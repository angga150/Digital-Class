# Laravel Application

Folder ini adalah **source code utama Digital Class Universe**.

Aplikasi menggunakan:

- Laravel
- Livewire
- Blade
- Tailwind CSS
- MySQL

Saat project Laravel sudah dibuat, struktur internal folder ini harus mengikuti convention Laravel.

Contoh:

```text
src/
├── app/
├── config/
├── database/
├── public/
├── resources/
├── routes/
├── storage/
├── tests/
├── artisan
├── composer.json
└── package.json
```

Jalankan command Laravel dari folder `src/`.

```bash
cd src
php artisan serve
```
