# Feature Specification: Events

## 1. Status
Planned (Next Scope)

## 2. Tujuan
Mengelola jadwal kegiatan kelas, jadwal kumpul, deadline tugas kuliah, dan agenda penting lainnya dalam satu kalender yang transparan.

## 3. User Flow
1. Pengguna membuka menu Events.
2. Melihat daftar kegiatan mendatang berdasarkan kronologi waktu.
3. Admin dapat menambahkan event baru (judul, tanggal, deskripsi, lokasi).
