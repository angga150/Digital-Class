# Feature Specification: Posts & Feed

## 1. Status
Planned (Next Scope)

## 2. Tujuan
Wadah bagi mahasiswa untuk berbagi cerita santai, meme kelas, informasi penting, atau diskusi ringan sehari-hari.

## 3. User Flow
1. Pengguna menulis teks atau mengunggah gambar pada kolom kiriman di feed.
2. Postingan langsung muncul di linimasa kelas secara kronologis terbalik.
3. Anggota lain dapat memberikan komentar atau tombol suka (*like*).
