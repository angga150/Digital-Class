# Feature Documentation

Setiap feature document harus menjawab:

- Apa tujuan feature?
- Bagaimana user flow-nya?
- Apa business rules-nya?
- Data apa yang dipakai?
- Siapa yang boleh melakukan aksi?
- Apa validation dan edge case-nya?
- Apa yang harus dites?
