# Feature Specification: Members

## 1. Status
Active (MVP Scope)

## 2. Tujuan
Direktori digital seluruh anggota kelas yang memuat foto profil, nama lengkap, keahlian/minat IT, serta tautan media sosial pribadi.

## 3. User Flow
1. Pengguna membuka menu Members.
2. Menggunakan fitur pencarian untuk mencari teman berdasarkan nama atau keahlian.
3. Mengklik profil untuk melihat detail informasi kontak/sosial media.
