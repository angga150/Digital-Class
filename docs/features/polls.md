# Feature Specification: Polls

## 1. Status
Planned (Next Scope)

## 2. Tujuan
Membuat pemungutan suara cepat untuk kebutuhan kelas (misal: menentukan jadwal kerja kelompok, tempat nongkrong, atau pemilihan ketua acara).

## 3. User Flow
1. Pengurus atau anggota membuat polling dengan beberapa pilihan jawaban.
2. Anggota memberikan suara (*vote*).
3. Hasil persentase voting langsung diperbarui secara interaktif.
